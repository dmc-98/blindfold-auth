# Support

## Getting help

Start with the canonical docs:

- `docs/MASTER_GUIDE.md`
- `README.md`
- `docs/ARCHITECTURE.md`

## Where to ask what

- bug reports: open a GitHub issue using the bug report template
- feature requests: open a GitHub issue using the feature request template
- security issues: follow `SECURITY.md` and report privately
- contribution questions: read `CONTRIBUTING.md`

## What to include in a support request

Include enough detail to reproduce or reason about the issue:

- which package or example you are using
- which deployment lane you are using
- the command you ran
- expected behavior
- actual behavior
- logs or screenshots when relevant
